# Heatmap style parameters

Colours and graphical parameters for each
[`plot_heatmap()`](https://TeamMacLean.github.io/paneffectR/reference/plot_heatmap.md)
style. Hues are taken from a palette validated for colour-vision
deficiency: Core blue, Accessory green and Unique orange are mutually
distinguishable under the common deficiencies.

## Usage

``` r
heatmap_style(style)
```

## Arguments

- style:

  One of "clean", "pan", "mono".

## Value

A named list.
